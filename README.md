# licitacao-lab

Monorepo de estudo (Etapa 1) com estrutura inicial para backend, frontend e serviços auxiliares em containers.

## Estrutura inicial

- `backend/`
- `frontend/`
- `docs/`
- `docker-compose.yml`
- `.env.example`

## Subir ambiente

Com Docker e Docker Compose instalados, execute:

- `docker compose up --build`

Nesta etapa, backend e frontend estão como containers-base e serão implementados nas próximas etapas.
